# Special-issue event calendar

A week is a **special issue** if the main keynote day of one of these events falls in the issue's coverage window
(see `editorial/prompt.md` → *Special issues*). The list is closed and in priority order. Only the publisher adds events
to it. The routine may only update dates, and only from the event's official page or the organiser's announcement.

## Qualifying events (priority order)
1. OpenAI DevDay — usually autumn
2. Anthropic Code with Claude — usually May (the main keynote, not satellite city events)
3. Google I/O — usually May
4. Microsoft Build — usually May/June
5. Apple WWDC — usually June
6. Nvidia GTC (San Jose) — usually March
7. Meta Connect — usually September
8. AWS re:Invent — usually early December
